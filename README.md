# SafeCopy

Android-приложение, которое готовит «безопасную копию» документа, удостоверяющего личность,
перед передачей другому человеку или организации: закрашивает лишние поля, накладывает водяной знак
с получателем и целью, удаляет метаданные и ведёт журнал отправок. Всё обрабатывается на устройстве,
без доступа к интернету (152-ФЗ, принцип минимизации данных).

Полное техническое задание: [docs/ТЗ_SafeCopy.pdf](docs/ТЗ_SafeCopy.pdf).

## Структура репозитория

| Папка | Что внутри |
|---|---|
| `android/` | Android-проект (Kotlin, Jetpack Compose, MVVM, Hilt) |
| `docs/` | Техническое задание и прочая документация |

## Сборка

Нужна Android Studio (последняя стабильная). Откройте в ней папку **`android/`**, не корень репозитория.

Из командной строки:

```bash
cd android
./gradlew assembleDebug      # APK: app/build/outputs/apk/debug/
./gradlew testDebugUnitTest  # unit-тесты
```

Минимальная версия Android — 8.0 (API 26).
